# Provider catalog

YAML-описания источников тайлов. Один файл — один провайдер.

## Поля

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | стабильный идентификатор, латиница |
| `name` | да | отображаемое имя |
| `type` | да | `xyz`, `tms`, `wmts`, `wms` |
| `url` | да | шаблон с `{z}`, `{x}`, `{y}` или WMS-параметрами |
| `scheme` | да | `xyz` или `tms` |
| `min_zoom`, `max_zoom` | да | допустимый диапазон |
| `tile_size` | да | 256 или 512 |
| `format` | да | `png`, `jpg`, `webp` |
| `attribution` | да | строка для UI и паков |
| `terms` | да | ссылка на условия использования |
| `rate_limit` | нет | `rps`, `burst` |
| `headers` | нет | дополнительные заголовки |
| `auth` | нет | `none`, `header`, `query`, `basic` |
| `offline_allowed` | нет | разрешён ли pre-fetch тайлов для офлайна; по умолчанию `false` |

## Правила

- В репозиторий не попадают ключи и токены.
- Массовое скачивание допускается только если это разрешено условиями
  провайдера. Флаг `offline_allowed: true` — обещание, что pre-fetch
  разрешён; его нельзя ставить без проверки ToS.
- `User-Agent` должен идентифицировать приложение и контакт.
- Для коммерческих источников — отдельный provider с `auth`.

## Встроенные источники

| ID | Офлайн | Примечание |
|---|---|---|
| `osm` | нет | политика OSM запрещает offline и bulk pre-fetch |
| `topo` | нет | трафик сообщества |
| `carto` | нет | условия CARTO |
| `usgs` | да | USGS The National Map, public domain |

Офлайн-очередь блокирует провайдеров с `offline_allowed: false` и
показывает причину в UI. Собственный источник можно добавить с этим
флагом, если его условия это разрешают.

## Статус

Каталог синхронизирован с `ui/src/providers.ts`. В нативном приложении
YAML встроен в бинарник и отдаётся через `list_providers`; браузерная
сборка использует статический список.

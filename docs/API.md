# Mappa serve: tile server and REST API

`mappa serve` раздаёт тайлы из общего дискового кэша и локальные
MBTiles/PMTiles, плюс небольшой read-only REST API. Сервер не требует
GUI и работает на том же кэше, что приложение и CLI.

```bash
# локально
mappa-cli serve --port 8080

# в LAN: телефоны, QGIS, другой ноутбук
mappa-cli serve --host 0.0.0.0 --port 8080 --token mappa-lan

# кэш + один или несколько паков
mappa-cli serve \
  --pack ~/maps/crimea.mbtiles \
  --pack ~/maps/city.pmtiles \
  --port 8080
```

По умолчанию кэш берётся из `~/.cache/dev.mappa.desktop/tiles.sqlite3`,
очередь — из `downloads.sqlite3` рядом с ним. Пути можно задать через
`--cache`, `--queue` и `MAPPA_CACHE`.

При старте печатаются локальный и LAN-адреса. Если порт занят, сервер
завершается с понятной ошибкой; `--port 0` выбирает свободный порт.
Для LAN-адреса в терминале печатается QR-код: наведите камеру телефона,
чтобы открыть сервер. Токен уже включён в QR-ссылку.

## QR-код

```bash
# QR в терминале и SVG-копия
mappa-cli serve --host 0.0.0.0 --token mappa-lan \
  --qr-svg ~/mappa-lan.svg
```

- QR печатается, когда сервер слушает LAN или явный не-loopback адрес;
  для `127.0.0.1` он не нужен и не выводится.
- `--no-qr` отключает вывод в терминале, `--qr-svg PATH` сохраняет
  изображение 320×320 с белым полем.
- Поддерживаются URL до ~213 байт (QR версии 1–10, уровень коррекции M).
  Длинный токен может не поместиться — сервер предупредит, а ссылка
  останется в строке `LAN:`.
- QR содержит токен доступа: не публикуйте скриншот терминала.

## Аутентификация

Без `--token` сервер открыт всем, кто до него дотягивается. Для LAN
используйте токен:

- `?token=...` в URL;
- или заголовок `Authorization: Bearer ...`.

`/health` всегда публичный. Токен не заменяет TLS: в недоверенной сети
публикуйте сервер только через VPN/обратный прокси.

## Очередь заданий

- `GET /api/jobs` — список заданий;
- `GET /api/jobs/{id}` — одно задание;
- `POST /api/jobs` — поставить загрузку:
  `{provider, bbox:[west,south,east,north], minZoom, maxZoom, name?, polygon?, sourceIds?}`.
  Заголовок `Idempotency-Key` (или поле `idempotencyKey`) возвращает
  существующее задание вместо дубля. Ответ `202`, повтор — `200`.
- `--no-worker` отключает фоновый воркер: задания только ставятся в очередь.

## Синхронизация и мобильный компаньон

- `GET /api/sync` — список проектов;
- `GET /api/sync/{name}` — снимок проекта;
- `PUT /api/sync/{name}` — запись с LWW по `savedAt`, `?force=1`;
- `GET /m` — мобильная страница записи трека;
- `POST /api/track` — `{name, points:[{lat,lon,alt?,time?}]}` → GPX.

`mappa serve --tls` включает HTTPS с самоподписанным сертификатом:
без него браузер на телефоне не даст GPS.

## REST

Все ответы — JSON, кроме тайлов, `/health` и текстовой страницы `/`.
API read-only: очередь можно смотреть, но нельзя менять задания.
Пакетные download/pack-задания запускаются через
`mappa-cli batch` — см. [BATCH.md](BATCH.md).

| Метод | Путь | Что возвращает |
|---|---|---|
| GET | `/health` | `ok` |
| GET | `/api/status` | версия, uptime, путь и статистика кэша, число провайдеров/паков/заданий |
| GET | `/api/providers` | каталог провайдеров и шаблоны tile URL |
| GET | `/api/packs` | открытые паки, bbox, зум-диапазон, формат (`png`, `jpg`, `mvt`), число тайлов |
| GET | `/api/jobs` | очередь загрузок: статус, прогресс, байты, ошибка |
| GET | `/style/{provider}.json` | готовый MapLibre raster style |
| GET | `/tiles/{provider}/{z}/{x}/{y}` | тайл из дискового кэша |
| GET | `/packs/{id}/{z}/{x}/{y}` | тайл из MBTiles или PMTiles; MVT отдаётся как `application/vnd.mapbox-vector-tile` |
| OPTIONS | любой | CORS preflight |

У тайловых путей допускается расширение (`.png`, `.jpg`), оно не влияет
на выбор данных. Поддерживаются `GET` и `HEAD`.

### Примеры

```bash
curl http://127.0.0.1:8080/api/status
curl 'http://127.0.0.1:8080/api/jobs?token=mappa-lan'
curl -o tile.png 'http://127.0.0.1:8080/tiles/carto/11/1238/640.png'
```

MapLibre:

```text
http://127.0.0.1:8080/style/topo.json
```

QGIS → XYZ Tiles:

```text
http://127.0.0.1:8080/tiles/topo/{z}/{x}/{y}.png
```

Для пака URL берётся из `/api/packs` (`tileUrl`), например:

```text
http://127.0.0.1:8080/packs/pack-1/{z}/{x}/{y}
```

## Коды ответов

| Код | Когда |
|---|---|
| 200 | успех |
| 204 | CORS preflight |
| 400 | некорректные z/x/y |
| 401 | нужен или неверен токен |
| 404 | нет маршрута, провайдера, пака или тайла |
| 405 | метод кроме GET/HEAD/OPTIONS |
| 431 | заголовки больше 16 КиБ |
| 500 | ошибка кэша или пака |

Тайл, которого нет в кэше, возвращает 404 с подсказкой запустить
`mappa-cli download`. Это ожидаемое поведение: сервер не ходит в сеть
самостоятельно.

## Ограничения

- Одновременно обслуживается до 64 соединений, соединение закрывается
  после одного запроса (`Connection: close`).
- Нет TLS, range-запросов и кэширования 304. ETag тайла из кэша
  отдаётся в ответе.
- REST не меняет очередь и настройки; batch-задания запускаются из CLI.
- PMTiles читается через memory-map; MBTiles — через SQLite только для
  чтения.

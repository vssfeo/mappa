# AI usage disclosure

Mappa is developed with AI coding assistants. They are used for code
generation and refactoring, test scaffolding, documentation drafts and
review suggestions. The maintainer reviews the changes, runs the test
suite, checks the builds and makes the release decisions.

AI is not used to generate map data, satellite imagery or user content.
The project does not ship model weights or call an AI service at runtime.

This disclosure exists so directories and reviewers can judge the project
on its code, tests and field behaviour rather than on how the code was
typed.

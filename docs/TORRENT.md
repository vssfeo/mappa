# Обмен паками (BitTorrent)

Mappa создаёт `.torrent` и magnet для готового MBTiles/PMTiles, но **не
качает сама**: загрузку выполняет ваш торрент-клиент (qBittorrent,
Transmission и т. п.).

## Поделиться

1. `Ctrl+K` → «Поделиться паком».
2. Выберите открытый пак.
3. «Создать торрент» → сохраните `.torrent`.
4. Скопируйте magnet или нажмите «Открыть в торрент-клиенте».

Формат — BitTorrent v1 (SHA1, куски 256 КиБ до 16 МиБ, дальше 1 МиБ).
Трекер не прописывается: поиск пиров идёт через DHT и Local Peer
Discovery вашего клиента. Для локальной сети без интернета включите
LSD в клиенте.

## Получить

Magnet открывается системным обработчиком. После скачивания откройте
пак в Mappa через «Слои» → импорт пака (папка загрузок клиента).

## Ответственность

Mappa не проверяет лицензии и не раздаёт данные сама. Создавая торрент,
вы отвечаете за право распространять пак; для Яндекс/Google/Esri это
может нарушать условия. Для USGS/OSM и собственных данных ограничений
меньше.

## Ограничения

- Нет встроенного клиента: прогресс, пиры и сидирование — в вашем
  торрент-клиенте.
- Нет автоматического импорта после скачивания.
- Нет своего трекера.
- BLAKE3-манифест Mappa не входит в `.torrent`; проверяйте пак отдельно.

# Полевой комплект

«Полевой комплект» собирает переносимую папку для USB/SD-карты:

```
Mappa-field/
  project.mappa      текущий проект
  packs/00-*.mbtiles выбранные паки
  dem/*.hgt          выбранный DEM
  manifest.json      размеры и BLAKE3 всех файлов
  README.txt
```

## Как собрать

1. `Ctrl+K` → «Полевой комплект».
2. Выбери папку-назначение (Mappa создаст `Mappa-field` или `Mappa-field-2`).
3. Отметь проект, паки и DEM.
4. «Собрать».

Файлы проверяются по BLAKE3 при копировании; большие паки хэшируются
потоково, без чтения в память. Ключи своих источников и пользовательские
XYZ/WMS в комплект **не попадают** — только пути проекта.

## Ограничения

- Нет треков и произвольных файлов: только проект, паки и DEM.
- Нет прогресс-бара: для пака в несколько гигабайт окно будет занято.
- BLAKE3, не SHA256; для проверки используйте `b3sum` или Mappa.
- Папка не архивируется: копирование целиком.

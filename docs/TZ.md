## 1. Видение

Mappa — настольное приложение для просмотра, скачивания и использования
карт и спутниковых снимков без сети. Linux-first, с последующим
Windows/macOS. Не GIS-комбайн и не клон QGIS: фокус на скорости,
офлайне, качестве UI и автоматизации.

### 1.1. Главный сценарий

1. Пользователь открывает Mappa.
2. Находит место через поиск или вставляет координаты.
3. Выбирает подложку.
4. Рисует прямоугольник/полигон.
5. Видит оценку: тайлы, размер, время.
6. Ставит скачивание в очередь.
7. Получает один `.pmtiles`-пак.
8. Уходит в поле/на робота, где сети нет, и открывает пак.
9. При необходимости раздаёт карту по LAN или забирает её через CLI.

### 1.2. Кого заменяем

| Продукт | Что берём | Где делаем лучше |
|---|---|---|
| SAS.Planet | провайдеры, кэш, скачивание районов | UI, Linux, офлайн-паки, CLI, скорость |
| QGIS | базовые слои, измерения, экспорт | простота, скорость запуска, download UX |
| MOBAC | массовая выгрузка тайлов | живой просмотр, кэш, очередь, паки |
| QMapShack | треки, офлайн-карты | современный UI, провайдеры, автоматизация |

## 2. Цели и не-цели

### 2.1. Цели v1.0

- Открыть карту менее чем за 1,5 с после запуска (тёплый кэш).
- Плавный pan/zoom 60 fps на 1440p.
- Скачать 10 000 тайлов без падений, с pause/resume.
- Экспорт/импорт MBTiles и PMTiles.
- 10+ легальных провайдеров из коробки.
- Добавление своего XYZ/WMTS-провайдера за 2 минуты через UI.
- CLI для headless-скачивания и сборки паков.
- Локальный tile-server для других устройств в LAN.
- Тёмная и светлая темы, полная клавиатурная навигация.
- Linux x86_64 AppImage/deb/Flatpak; ARM64 — сборка и базовый smoke-тест.

### 2.2. Не-цели v1.0

- Полноценная GIS-редактура и топология.
- Фотограмметрия, построение ортофотопланов.
- Собственный роутинг-движок (только внешние ссылки/плагины).
- Скрейпинг Google/Yandex/Esri «из коробки».
- Мобильные приложения (позже — PWA/field web).
- Облачный аккаунт, командная синхронизация, SSO.
- Поддержка Windows/macOS в первом релизе (архитектура готова, сборки позже).

### 6.2. Rust workspace

```text
crates/
  mappa-core/      # Web Mercator, tile math, providers, queue, jobs
  mappa-storage/   # SQLite cache, MBTiles, PMTiles, pack manifest
  mappa-net/       # HTTP, retry, rate limit, proxy, auth
  mappa-server/    # axum tile server + REST
  mappa-cli/       # clap CLI
  mappa-app/       # Tauri commands, app state
ui/                # React/TS/MapLibre
providers/         # YAML catalog
docs/
```

### 6.3. Почему Rust + Tauri

- Один бинарник, быстрый старт, низкая память.
- Хорошая async-экосистема для сетевой очереди.
- Кросс-компиляция на ARM64.
- Tauri даёт маленький размер и нативные диалоги.
- MapLibre GL JS — зрелый GPU-рендеринг и 3D.

Риск: WebKitGTK на Linux. Смягчение: тесты на трёх дистрибутивах,
запасной вариант — локальный HTTP tile-server вместо custom protocol.

### 6.4. Потоки данных

1. UI просит тайл через `tile://` protocol или локальный HTTP.
2. `mappa-core` проверяет память → диск → сеть.
3. Сетевой запрос coalesce по ключу; приоритет viewport > prefetch > bulk.
4. Ответ валидируется, пишется атомарно, отдаётся в UI.
5. Download job пишет в очередь и кэш; прогресс идёт в UI событиями.

## 7. Данные и форматы

### 7.1. Кэш SQLite

```sql
CREATE TABLE tiles (
  provider_id TEXT NOT NULL,
  z INTEGER NOT NULL,
  x INTEGER NOT NULL,
  y INTEGER NOT NULL,
  format TEXT NOT NULL,
  etag TEXT,
  last_modified TEXT,
  fetched_at INTEGER NOT NULL,
  expires_at INTEGER,
  data BLOB NOT NULL,
  hash TEXT NOT NULL,
  PRIMARY KEY (provider_id, z, x, y, format)
);
CREATE INDEX tiles_expires ON tiles(expires_at);
```

- WAL, `synchronous=NORMAL`.
- Лимит и LRU по `fetched_at`/`last_used`.
- Для больших паков — отдельные файлы, не в SQLite.

### 7.2. Пак

- PMTiles v3 — основной формат.
- MBTiles — совместимость.
- Манифест `.mappa-pack.json`: id, name, bbox, zooms, provider,
  created_at, license, attribution, sha256, signature.
- Подпись Ed25519; проверка при импорте (опционально strict mode).

### 7.3. Проект

`.mappa.json`: версия, view, layers, providers, marks, tracks,
bookmarks, download jobs (опционально), настройки.

## 8. Провайдеры и право

- В поставке — только источники, разрешающие использование:
  OSM, OpenTopoMap, CARTO, USGS The National Map.
- Google/Yandex/Esri не вшиваются. Пользователь может добавить URL
  вручную; приложение показывает предупреждение о ToS.
- Уважать `rate_limit`, `Retry-After`, `User-Agent`, кэш-заголовки
  (включая `Age`).
- Не обходить авторизацию, капчу и платные API.
- Офлайн-pre-fetch разрешён только при `offline_allowed: true` в
  провайдере. Для OSM он запрещён: политика допускает лишь кэш
  просмотренных тайлов и не разрешает офлайн-скачивание. Поэтому
  встроенная очередь работает с USGS, а не с OSM.
- В паках хранить лицензию и attribution; при экспорте — не удалять.

## 9. Качество и приёмка

### 9.1. Definition of Done для фичи

- Есть acceptance criteria и тесты.
- Работает мышью и с клавиатуры.
- Есть loading/empty/error/offline состояния.
- Длинная операция отменяема.
- Ошибка содержит действие («повторить», «открыть настройки»).
- Нет блокировки UI > 100 мс.
- Локализация RU/EN.
- Обновлена документация.

### 9.2. Тесты

- Unit: tile math, provider parsing, cache keys, pack manifest.
- Property-based: bbox/zoom/tile ranges, координаты.
- Integration: mock HTTP, retry, rate limit, SQLite crash.
- E2E: Tauri WebDriver/Playwright — открыть карту, скачать 100 тайлов,
  экспортировать пак, импортировать.
- Performance: criterion для tile math/cache; ручной benchmark UI.
- Fuzz: YAML-провайдеры, импорт паков.

### 9.3. Метрики успеха

- Время до первой карты ≤ 5 мин у нового пользователя.
- Скачивание 10 000 тайлов без вмешательства.
- 95% сессий без crash.
- Провайдер добавляется за ≤ 2 мин.
- Пак открывается на RK3399 в headless/tile-server режиме.

## 12. Глоссарий

- **Тайл** — квадратное изображение карты z/x/y.
- **Пак** — один файл с тайлами и метаданными (PMTiles/MBTiles).
- **Провайдер** — источник тайлов и правила доступа к нему.
- **Tile-server** — локальный HTTP-сервер, отдающий тайлы другим устройствам.
- **Полевой режим** — UI для солнца/перчаток/батареи.
- **Cache Doctor** — проверка и ремонт кэша.

# Mappa — UI/UX-концепция

**Версия:** 0.1  
**Дата:** 2026-10-23  
**Связанные документы:** [TZ.md](TZ.md), [ROADMAP.md](ROADMAP.md)

---

## 1. Принципы

1. **Карта — главный экран.** Никаких форм на весь экран. Всё, что можно
   сделать поверх карты, делается поверх карты.
2. **Спокойно, но плотно.** Интерфейс не кричит. Плотность как в
   профессиональном ПО, но без визуального шума.
3. **Всё обратимо.** Удаление, очистка кэша, отмена загрузки — с undo
   или подтверждением.
4. **Каждое действие — с клавиатуры.** Мышь удобна, клавиатура быстрее.
5. **Долгая операция не блокирует.** Прогресс живёт в отдельном центре,
   карта остаётся отзывчивой.
6. **Ошибка говорит, что делать.** Не «Error 500», а «Сервер не ответил.
   Повторить / сменить провайдер / открыть настройки».
7. **Никакой скрытой сети.** Индикатор сети и кэша всегда на виду.

## 2. Экран

```text
┌────────────────────────────────────────────────────────────────────┐
│  Mappa   [Поиск или Ctrl+K]        [Провайдер ▾]   [Скачать]  [⚙]  │
├──────┬──────────────────────────────────────────────────┬──────────┤
│ Rail │                                                  │ Inspector│
│      │                     MAP                          │          │
│  ◉   │                                                  │  Слои    │
│  ▤   │                                                  │  Свойства│
│  ⤓   │                                                  │  Инфо    │
│  ★   │                                                  │          │
│      │                                                  │          │
├──────┴──────────────────────────────────────────────────┴──────────┤
│ z14  ·  1:50 000  ·  55.7558, 37.6173  ·  кэш 82%  ·  сеть 1.2 МБ/с │
└────────────────────────────────────────────────────────────────────┘
```

- **Rail** — иконки: карта, слои, загрузки, закладки, проекты.
- **Top bar** — командная строка, провайдер, главное действие «Скачать».
- **Inspector** — контекстная панель справа: свойства слоя, метки,
  оценка скачивания, информация о тайле.
- **Status bar** — зум, масштаб, координаты, состояние кэша и сети.
- Всё скрывается по `F11` / режим «только карта».

## 3. Ключевые сценарии

### 3.1. Первый запуск

1. Приветствие на 3 шага, без регистрации.
2. Выбор темы: «Graphite» (тёмная) / «Paper» (светлая) / «System».
3. Кнопка «Показать демо-район» — сразу карта, а не пустой экран.
4. Подсказка: `Ctrl+K` — все команды; `?` — шпаргалка.

Никаких мастеров на 10 экранов. Всё можно пропустить.

### 3.2. Скачивание района

1. Кнопка **Скачать** или `D`.
2. На карте появляется прямоугольник с ручками; режим «полигон» — `Shift+D`.
3. Inspector показывает:
   - провайдер и слой;
   - зумы `10–17` с ползунком;
   - тайлов: `12 480`;
   - размер: `~1,8 ГБ`;
   - время: `~6 мин` при текущей скорости;
   - кнопка **В очередь**.
4. После постановки — тост «Добавлено в очередь» и переход в **Центр загрузок**.
5. Очередь: прогресс-бар, скорость, ETA, пауза, отмена, «открыть папку».

Оценка обновляется живьём при движении области и ползунка зумов.
Если размер > свободного места — красная строка и кнопка «Уменьшить зумы».

### 3.3. Сравнение подложек

- `C` — режим сравнения.
- Две подложки, вертикальная «шторка» с ручкой.
- Слева/справа подписи провайдеров.
- `Shift+C` — поменять местами.
- `Esc` — выйти.

### 3.4. Измерение

- `M` — линейка. Клики добавляют точки, двойной клик завершает.
- Панель снизу: длина, азимут, координаты точек.
- `Shift+M` — площадь.
- `Backspace` — убрать последнюю точку, `Esc` — отмена.

### 3.5. Полевой режим

- `F` — полевой режим: крупные кнопки, высокий контраст, минимум
  анимаций, координаты крупным шрифтом.
- Быстрые действия: «моя позиция», «ближайшая метка», «записать трек».
- Экран не гаснет (опционально), батарея экономится.

### 3.6. Робот / LAN

- `Ctrl+Shift+S` — запустить tile-server.
- Панель: адрес `http://192.168.1.10:8080`, QR-код, количество
  подключённых клиентов, отдано тайлов.
- Кнопка «Скопировать URL для MapLibre/OsmAnd».

## 4. Командная палитра

`Ctrl+K` — единая точка входа.

Группы:

- **Перейти:** координаты, место, закладка, проект.
- **Слой:** сменить провайдера, добавить слой, сравнить.
- **Скачать:** прямоугольник, полигон, текущий экран, пак.
- **Инструменты:** линейка, площадь, метка, трек.
- **Настройки:** тема, кэш, прокси, клавиши.
- **Недавние** и **избранное**.

Поведение:

- Ввод фильтрует мгновенно, без спиннера.
- `↑/↓` — выбор, `Enter` — выполнить, `Tab` — параметры.
- Команды с параметрами показывают inline-поля, а не новый экран.
- Пустой результат: «Ничего не найдено. Попробовать координаты?»

## 5. Дизайн-система

### 5.1. Темы

| Токен | Graphite (dark) | Paper (light) |
|---|---|---|
| `bg.canvas` | `#0E1116` | `#F6F4EF` |
| `bg.panel` | `#151A21` | `#FFFFFF` |
| `bg.elevated` | `#1C232C` | `#FFFFFF` |
| `text.primary` | `#E8EDF2` | `#151A21` |
| `text.secondary` | `#9AA7B4` | `#5B6672` |
| `border.subtle` | `#26303A` | `#E2DED4` |
| `accent` | `#FF7A45` (signal orange) | `#D9541E` |
| `accent.alt` | `#43D9C5` (teal) | `#0F8F7E` |
| `danger` | `#FF5C5C` | `#C62F2F` |
| `success` | `#58D68D` | `#1E8E4E` |

Акцент — оранжевый «signal», не стандартный синий. Teal — для
служебных состояний (кэш, сеть).

### 5.2. Типографика

- UI: **Inter** (или system-ui fallback).
- Координаты/код: **JetBrains Mono**.
- Размеры: 11 / 12 / 13 / 14 / 16 / 20 / 24.
- Заголовки — 600, текст — 400/500.
- Цифры в статус-баре — tabular.

### 5.3. Сетка и форма

- Базовая сетка 4 px, отступы 8/12/16/24.
- Радиусы: 6 px (controls), 10 px (panels), 14 px (sheets).
- Тени минимальны; границы важнее теней.
- Иконки: Lucide, толщина 1.5–1.75.
- Плотность: compact / comfortable (настройка).

### 5.4. Движение

- 120–180 мс, ease-out.
- Панели выезжают, но карта не «прыгает».
- `prefers-reduced-motion` — без анимаций.
- Прогресс-бары анимируются только при активной загрузке.

## 6. Компоненты

### 6.1. Inspector

Правая панель, 320–380 px. Секции сворачиваются. Контент зависит
от контекста:

- **Слой:** провайдер, непрозрачность, порядок, кэш, лицензия.
- **Скачивание:** область, зумы, оценка, кнопка.
- **Метка:** имя, цвет, иконка, координаты, заметка.
- **Тайл:** z/x/y, провайдер, размер, возраст, «открыть в новой вкладке».

### 6.2. Центр загрузок

Отдельная панель/окно (`Ctrl+J`):

- Активные, в очереди, завершённые, ошибки.
- Прогресс, скорость, ETA, размер.
- Пауза/продолжить/отмена/повторить.
- Группировка по провайдеру/проекту.
- «Очистить завершённые» с undo.

### 6.3. Тост

- Снизу справа, 4–6 с.
- Одно действие: «Отменить», «Открыть», «Повторить».
- Не перекрывает статус-бар и карту.

### 6.4. Диалоги

- Только для destructive/критичных действий.
- Всё остальное — sheet/panel.
- `Esc` закрывает, фокус возвращается.

### 6.5. Пустые состояния

- «Пока нет слоёв. Добавить провайдера?»
- «Кэш пуст. Скачать текущий экран?»
- «Нет загрузок. Выбрать район?»

С каждой пустой строкой — одна кнопка действия.

## 8. Состояния и обратная связь

| Состояние | UI |
|---|---|
| Загрузка тайла | skeleton/placeholder цвета фона, без «крутилки» на каждом тайле |
| Нет сети | жёлтая полоса «Офлайн. Показано из кэша» + кнопка «Повторить» |
| Ошибка провайдера | красная строка в Inspector + «Сменить провайдер» |
| Кэш переполнен | диалог с размером и кнопкой «Очистить старейшие» |
| Долгая операция | прогресс в статус-баре + центр загрузок, карта активна |
| Опасное действие | подтверждение с явным именем объекта |

Никаких модальных «Пожалуйста, подождите». Никаких блокирующих
спиннеров на весь экран.

## 9. Онбординг

- 3 карточки: «Карта», «Скачать», «Офлайн».
- Демо-пак с Москвой/Питером (легальный источник) — 20–50 МБ.
- Интерактивная подсказка: нарисуй прямоугольник, скачай 3 тайла.
- «Импортировать из SAS.Planet» — отдельная кнопка.

Цель: пользователь скачал первый пак за ≤ 3 минуты.

---

## 10. Signature-моменты

1. **Мгновенный зум.** Карта не «плывёт» и не показывает белые квадраты.
2. **Живая оценка.** Тянешь прямоугольник — цифры размера/времени
   обновляются без лагов.
3. **Шторка сравнения.** Две подложки, плавно, без перезагрузки.
4. **Один файл.** «Экспортировать пак» → файл, который открывается везде.
5. **QR на карту.** Телефон/планшет в LAN открывает карту с борта.
6. **Cache Doctor.** Одна кнопка: проверил, нашёл битые, починил.
7. **Полевой режим.** Крупно, контрастно, перчатки, солнце.
8. **Командная палитра.** Всё управляется с клавиатуры, как в Linear/Raycast.

## 11. Доступность

- Контраст текста ≥ 4.5:1, крупного ≥ 3:1.
- Фокус виден всегда, не только по Tab.
- Все иконки имеют `aria-label`.
- Карта управляется клавиатурой: стрелки, `+/-`, `Home`.
- Не полагаться только на цвет: ошибки/успех дублируются иконкой/текстом.
- Масштаб UI 100–200% без поломки layout.
- `prefers-reduced-motion` отключает анимации.

---

## 12. Микрокопирайтинг

- Коротко, по делу, без канцелярита.
- Кнопка = глагол: «Скачать», «Повторить», «Открыть папку».
- Ошибка = что случилось + что сделать.
- Не «Ошибка валидации», а «URL не отвечает. Проверьте адрес или прокси».
- Не «Успешно», а «Пак сохранён: moscow.pmtiles».

---

## 13. Анти-паттерны

- Модальное окно на каждое действие.
- Скрытые настройки в глубоком дереве.
- Прогресс только в заголовке окна.
- Белые квадраты без skeleton.
- Провайдеры, которые нельзя удалить/отключить.
- Тёмная тема «чёрный на чёрном».
- Анимации ради анимаций.
- Кнопка «ОК» без объяснения последствий.

---

## 14. Референсы

- **Linear** — командная палитра, плотность, скорость.
- **Raycast** — единая командная строка.
- **Figma** — панели и контекстные действия.
- **Mapbox Studio** — слои и стили.
- **QGIS** — профессиональные инструменты, но без его тяжести.
- **SAS.Planet** — привычные провайдеры и сценарий «скачать район».

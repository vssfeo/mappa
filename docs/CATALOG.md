# Статический каталог паков

Каталог хранит только метаданные паков; сами тайлы качаются торрентом.
Он лежит в `catalog/catalog.json` и раздаётся как обычный файл, например
через GitHub Pages или raw.githubusercontent.com.

## Формат

См. `catalog/schema.json` и `catalog/README.md`.

Запись содержит:

- `id` — уникальный слаг;
- `name`, `provider`, `license`, `publisher`;
- `bbox` — west, south, east, north;
- `zoom` — min, max;
- `bytes`, `infoHash`, `magnet`;
- `publishedAt`.

## Публикация

1. В Mappa: «Поделиться паком» → «Создать торрент».
2. Заполнить лицензию/источник.
3. «Скопировать запись каталога».
4. Вставить запись в `packs` в `catalog/catalog.json` и обновить
   `updatedAt`.
5. Открыть PR. CI проверяет JSON через `scripts/catalog-check.mjs`.

В «Поделиться паком» есть кнопка **«Открыть issue каталога»**: она
открывает GitHub Issue с готовым JSON и чек-листом; модератор переносит
запись в `catalog/catalog.json` через PR. Ручное копирование осталось
для зеркал и своего каталога.

## Клиент

`Ctrl+K` → «Каталог паков». По умолчанию читается
`https://raw.githubusercontent.com/vssfeo/mappa/main/catalog/catalog.json`.
Можно указать зеркало или свой каталог; URL запоминается.

Фильтры: текущий вид, активный провайдер, поиск по имени/лицензии/издателю.
«Скачать» передаёт magnet системному торрент-клиенту.

## Ограничения

- Нет live-статистики сидов.
- Публикация не мгновенная: PR и ревью.
- Нет подписей: доверие — к репозиторию/ревью.
- Каталог не хранит и не раздаёт тайлы; ответственность за права на
  пак — на издателе.

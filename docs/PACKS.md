# Офлайн-паки

Mappa открывает готовые архивы напрямую, без распаковки и без загрузки в
кэш. Пак остаётся отдельным файлом на диске; приложение читает из него
тайлы по мере показа карты.

## Форматы

| Формат | Содержимое | Статус |
|---|---|---|
| `.mbtiles` | растровые PNG/JPEG/WebP/AVIF | читается |
| `.pmtiles` | растровые PNG/JPEG/WebP/AVIF | читается |
| `.pmtiles` | векторные MVT (Mapbox Vector Tiles) | читается |
| `.mbtiles` | векторные MVT (Mapbox Vector Tiles) | читается |

Векторный PMTiles должен содержать metadata с массивом `vector_layers`.
У векторного MBTiles слои берутся из metadata `json` (`vector_layers`)
или определяются по `format` = `pbf`/`mvt`. Обычно такие архивы
создают `tippecanoe`, GDAL или другой экспортёр. Если metadata нет,
Mappa откажется открывать архив: без имён слоёв MapLibre не может
построить стиль.

Тайлы MVT в MBTiles часто сжаты gzip. Mappa распаковывает их на лету
(лимит 64 МиБ на тайл); brotli и Zstandard не поддерживаются.

## Как отображается векторный пак

Для каждого слоя `vector_layers[].id` создаются три стилевых слоя
MapLibre:

- полигоны — заливка `#4f8fba` с прозрачностью 22% и контуром;
- линии и контуры полигонов — линия `#2f6f9f`;
- точки — маркеры `#d97706` с белой обводкой.

Стиль намеренно нейтральный: у MVT нет единой схемы атрибутов и цветов.
Слои входят в общий список паков, их можно скрывать, менять прозрачность
и перетаскивать. Данные не редактируются и не попадают в таблицу
атрибутов; для редактирования импортируйте GeoJSON/KML/GPX как обычный
векторный слой.

## Ограничения

- Нет настройки стиля по полям, фильтров, подписей и выбора объектов
  внутри пака.
- Экспорт показывает прогресс и поддерживает отмену, но итоговый архив
  всё равно собирается одной операцией и требует места на диске.
- PMTiles с несколькими `vector_layers` и сотнями слоёв создаёт по три
  стилевых слоя на каждый источник; на практике лучше держать число
  слоёв разумным.
- Пак читается memory-mapped; файл нельзя удалять или перемещать, пока
  он открыт в приложении.

## Сервер

`mappa-cli serve --pack city.pmtiles` отдаёт растровые и векторные
паки по `/packs/{id}/{z}/{x}/{y}`. Для MVT используется MIME
`application/vnd.mapbox-vector-tile`, а `/api/packs` показывает
`format: "mvt"`.

## Восстановление

Пути паков сохраняются в проекте и localStorage. При следующем запуске
Mappa открывает их заново. Если файл пропал, путь удаляется из списка;
остальные паки продолжают работать.

# Geocoder

Поиск мест встроен в командную палитру `Ctrl+K`: начните вводить название,
и через 350 мс появятся локальные и онлайн-результаты. Выбор результата
перелетает к точке и показывает её в тосте.

## Как ищет

1. **Локальный индекс** — `geocode.json` в каталоге конфигурации
   приложения. Поиск по `name` и `label`, без сети; сначала точное
   совпадение, затем префиксы и вхождения.
2. **Photon** — `https://photon.komoot.io/api/`, если онлайн-поиск включён.
3. **Nominatim** — `https://nominatim.openstreetmap.org/search`, если Photon
   не ответил или ничего не нашёл.
4. Найденные онлайн-места добавляются в `geocode.json`, поэтому следующий
   такой же запрос работает офлайн.

Онлайн-запросы сериализованы и разделены интервалом 1,1 с, чтобы не
превышать лимиты публичных сервисов. Используется общий HTTP-прокси из
настроек. Полный дамп Nominatim/Photon пока не импортируется: локальная
база — это пользовательский gazetteer плюс кэш выполненных поисков.

## Настройки

«Настройки» → «Геокодер» → «Разрешить онлайн-поиск».

- Включено (по умолчанию): локальный поиск, затем Photon/Nominatim.
- Выключено: только `geocode.json` и ранее сохранённые результаты.
- В браузерной сборке Rust-команды нет; палитра сообщает, что поиск мест
  доступен в приложении.

## Формат `geocode.json`

Файл можно пополнять вручную. Принимается массив или объект `places`:

```json
{
  "places": [
    {
      "id": "camp-1",
      "name": "Лагерь",
      "label": "Лагерь, Северный склон",
      "lon": 37.62,
      "lat": 55.75,
      "kind": "camp",
      "source": "local"
    }
  ]
}
```

Обязательны `name`, `label`, `lon` и `lat`; `id` и `source` будут
сгенерированы при отсутствии. Координаты — WGS84. Лимиты: 32 МиБ и
50 000 записей; дубликаты `id` отбрасываются. Файл пишется атомарно с
правами `0600`, потому что содержит историю поисков.

## Ответ команды

`geocode_search(query, lang, limit)` возвращает:

```json
{
  "places": [
    {
      "id": "photon:R:2555133",
      "name": "Москва",
      "label": "Москва, Россия",
      "lon": 37.6174782,
      "lat": 55.7505412,
      "kind": "city",
      "source": "photon"
    }
  ],
  "online": true
}
```

Если оба онлайн-сервиса недоступны, `online` = `false`, а `warning` =
`online_unavailable`; локальные результаты при этом остаются. В браузере
`warning` = `native_only`.

## Ограничения

- Нет импорта полного дампа Nominatim/Photon и массового геокодирования.
- Поиск по адресам ограничен возможностями публичных Photon/Nominatim и
  их условиями использования.
- Онлайн-запрос отправляет введённую строку на Photon/Nominatim; при
  необходимости отключите онлайн-поиск в настройках.
